# Contributing

Thanks for your interest in improving gh-runner-kit!

## Types of Contributions Welcome

- **Bug reports** – runner failures, PowerShell errors, security issues
- **Feature requests** – reasonable quality-of-life improvements
- **Documentation** – typos, clarity, examples
- **Portability** – batch script version, Linux/Mac support (discuss in issue first)

## What's Out of Scope

- Significant feature expansion (this is intentionally minimal)
- Support for non-Docker runner backends
- Organization-level runner management (covered in main README)

## How to Contribute

1. Open an issue first to discuss the change
2. Fork and create a branch
3. Test your changes (especially PowerShell syntax and docker-compose behavior)
4. Submit a pull request with a clear description

## Security

If you find a security issue with secrets handling or privilege escalation, email konradcinkusz@gmail.com instead of opening a public issue.
